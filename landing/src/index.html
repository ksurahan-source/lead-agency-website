A FEW THINGS TO KNOW

HIOB와 LLM은 각각 무엇을 하나요?+

당신이 제작 방향을 정하면 LLM은 자료를 읽고 기획·수정안을 제안합니다. HIOB MCP는 허용된 프로젝트의 재료 생성·음성·편집·저장·렌더 도구를 연결합니다. 중요한 제작 선택과 유료 생성은 확인한 뒤 진행합니다.

Codex가 있어야 하나요?+

현재 시작 안내와 검증 기준은 Codex를 중심으로 제공합니다. 다른 MCP 지원 앱은 연결 방식과 도구 지원이 다를 수 있습니다. HIOB 가입과 AI 앱 로그인은 별도이며, Studio에서 내 프로젝트의 접근을 허용합니다.

내 컴퓨터에서도 사용할 수 있나요?+

Windows·macOS·Linux 설치 안내가 준비되어 있습니다. 운영체제별 렌더 준비 사항과 실제 검증 범위는 설치 안내에서 확인하세요. 연결 후 무료 진단으로 현재 환경을 먼저 점검합니다.

비용은 언제 발생하나요?+

회원가입과 연결 설정만으로 유료 생성은 실행되지 않습니다. 영상·AI 음성 등을 생성할 때 표시된 견적과 허용 한도, 크레딧 잔액을 확인합니다. 충전 방식은 크레딧 안내에서 확인하세요.
