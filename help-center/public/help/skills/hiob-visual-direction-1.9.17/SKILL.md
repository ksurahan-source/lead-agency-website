# 광고의 시각 방향 찾기

산출물은 고객이 선택할 수 있는 구체적인 시각 방향과 스타일프레임 설계다. 인간이 방향을 고르고 AI는 이미지로 판단할 수 있도록 선택지를 구체화한다. 이미 선택된 방향이 있으면 다시 경쟁안을 만들지 않는다.

## 브랜드의 의미를 화면 사건으로 바꾼다

고객이 제공한 제품 사실·원본 메시지·표현을 보존한다. 부족한 정보 중 방향을 바꾸는 것만 묻고, 나머지는 임시 가정으로 표시한다. 타깃이 느낄 변화 한 가지 → 화면 속 물리적 변화 → 제품이 그 변화에 필요한 이유를 연결한다. 추상적인 ‘프리미엄’에는 광택을, ‘역동적’에는 입자를 자동 배정하지 않는다.

방향이 미정이면 서로 **원리가 다른** 2–3안을 짧게 보여준다. 각 안에는 다음을 붙인다.
- 한 문장 광고 아이디어와 제품의 역할.
- 중심 소재, 변형 행동, 초현실적 규칙 하나, 지켜야 할 현실 기준.
- 대표 화면의 구도·카메라 거리·빛·실제 표면 디테일·여백.
- 시각 리듬: 반복 간격, 크기 대비, 밀도 변화, 시선의 흐름 중 필요한 것.
- 같은 아이디어가 장면 2–3개로 발전하는 방식과 실패 위험.

스타일 이름만 다른 3안은 선택지가 아니다. 제품이 제거되어도 똑같이 성립한다면 광고 아이디어를 다시 잡는다. 고객이 기존 스타일이나 레퍼런스를 지정했다면 그 이유를 구체적으로 이어받는다.

방향 비교는 먼저 짧게 한다. 고객이 세 장면을 요청했다면 각 방향에 세 장면씩 전부 확장하지 않는다. 별도 비교 기획서를 요청하지 않은 한, 추천 방향 하나를 **임시 선택**으로 표시해 요청한 총 장면 수만 상세화하고 다른 방향은 핵심 차이만 남긴다. 고객의 실제 선택이 있으면 그것을 우선한다.

## 한 장의 프롬프트에 들어갈 결정

`광고 의미 → 주 피사체/행동 → 공간/구도 → 재질과 빛 → 불가능한 규칙 → 접촉/반사/그림자 → 보존 조건 → 출력 용도` 순서로 작성한다. 순서는 도구 문법이 아니라 빠진 결정을 찾는 틀이다. ‘8K, cinematic, surreal, detailed’를 쌓는 것으로 대신하지 않는다. 짧고 모순 없는 지시부터 시작한다.

실사+환상에서는 얼굴·피부·중력·렌즈 등 무엇을 현실로 고정하고 무엇 하나를 불가능하게 할지 정한다. 환상은 피부 앞뒤의 가림, 옷에 닿는 그림자, 같은 광원의 반사처럼 장면과 물리적으로 상호작용해야 한다. 그래픽에서는 재료의 두께·거칠기·탄성·빛의 투과와 행동이 연결되어야 한다. [재질과 환상 예시](references/material-and-fantasy.md)를 필요할 때 읽는다.

## 이미지가 있어야 판단할 수 있다

프롬프트만 작성했으면 ‘이미지 미생성’으로 표시한다. 이미지를 만드는 기능이 현재 호스트에 실제 존재하는지, HIOB의 `model_catalog`가 해당 입력을 지원하는지 확인한다. 모델 목록은 실행 권한이 아니다. 유료 호출은 사용자의 범위·현재 프로젝트 견적/권한 안에서만 한다. 이미지 도구가 없으면 이미지가 있는 것처럼 쓰거나 동영상 도구에 가짜 image 모드를 넣지 않는다.

생성/제공 이미지를 실제로 본 뒤 아이디어 전달, 주목점, 재료의 설득력, 브랜드 고유성, 보존 조건으로 비교한다. 정지 이미지의 시각 리듬은 영상 박자·음악 동기화의 증거가 아니다. 선택 이유와 남은 불확실성을 기록하고, 다음에는 `hiob-reference-cards` 또는 준비된 카드가 있으면 `hiob-scene-planning`으로 간다.

## 인물이 등장하는 모든 컷의 육도 연기 (2026-10-08)

**모든 인물 컷은 육도 감정이 표정·시선·자세·손·움직임에 보여야 한다. 이미지의 감정이 영상·립싱크·최종 편집에서 사라지면 통과가 아니다.** 호스트가 저장된 `direction.assets[].realm/expression/action`을 읽어 장면의 시작 → 주요 행동 → 반응으로 연결한다. 지옥은 압박과 긴장, 축생은 두려움과 방어, 아수라는 경쟁과 좌절, 인간은 분투와 의심, 아귀는 갈망과 기대, 천상은 얻어낸 안도다. 한 컷에 한 감정을 출발점으로 삼고 기존 승인 연출을 우선한다.

손 전용 컷은 손의 긴장·속도·주저함/확신으로 표현한다. 인물 없는 컷에 사람을 추가하지 않는다. Seedance의 CHARACTER 150단어와 얼굴 없는 참조 규칙을 유지하고 연기는 SCENE AND ACTION에 둔다. 같은 나레이터·승인 전문·목소리·타이밍을 보존하며 감정 보완을 이유로 기존 음원을 자동 재합성하지 않는다.

`storyboard_compile`의 실제 prompt에 의도가 전달됐는지 확인한다. 이후 원본 영상과 립싱크 결과를 실제로 보고 `material_review.sceneChecks`의 `person_body.note`에 타임코드·의도·관측된 연기·손상 여부를 기록한다. 최종 MP4에서도 같은 컷을 다시 본다. 프롬프트 전달, 실제 표현, 립싱크 후 보존은 별도 판정이다. 누락 시 원본 연출과 해당 소재를 읽어 보완하고 기존 성공 소재를 재사용한다. 관찰 없이 pass를 만들거나 무표정 포트레이트로 대체하지 않는다. 막힌 경우 `error_record`에 같은 작업/incident ID와 복구 결과를 남긴다.
