# 오디오가 비지 않는 박자와 음악 존재감

사용 시점: 목소리가 늘어지거나 음악이 작거나 공백이 생길 때

## 음성을 시간 기준으로
직접 녹음/Typecast/혼합 선택을 유지한다. 직접 녹음은 원본을 보존하고 실제 발화·쉼으로 장면을 설계한다. 합성 권한 없이 대체 TTS를 호출하지 않는다. Typecast는 훅·설명·CTA 짧은 샘플로 어조를 비교한 뒤 선택 문장만 만든다.

## 세 층의 역할
목소리=의미, 음악=구간 사이 에너지, 효과음=화면 사건. 컷이 바뀔 때마다 음악을 다시 시작하지 않는다. 나레이터 문장이 끝나도 필요한 환경음/음악은 이어질 수 있다. 모든 공백을 효과음으로 채우거나 숨을 전부 지우지 않는다.

## 낮은 음악의 수리 순서
원본 소리가 작은지 → 파일에 이미 적용된 보정 → 클립/트랙 gain → 음소거 → 자동 감쇠 → 수동 페이드 순서로 중복 감소를 찾는다. 말을 알아들을 수 있는 수준에서 음악 존재감을 비교한다. 여러 gain을 동시에 올리거나 고정 퍼센트를 모든 곡에 적용하지 않는다. 실제 MP4를 휴대폰과 이어폰에서 확인한다.

## AI 프롬프트
각 의미 묶음의 [발화 시작·끝 | 의도적 쉼 | 음악의 유지/변화 | 화면 사건과 효과음 | 다음 묶음 연결]을 기록해. 의도 없는 2–3초 정지는 내용을 추가하거나 트림하고, 반응을 느낄 짧은 쉼은 남겨. 음성 끝을 자르지 말고 실제 녹음에 맞춰 그룹 경계를 수정해.

## 통과 기준
음량 수치와 실제 발음·감정·리듬을 별도 확인했다. 필요한 원본 대사와 나레이션이 빠지거나 겹치지 않고 음악이 장면을 연결한다.
