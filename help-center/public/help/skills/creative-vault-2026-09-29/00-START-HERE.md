# 시작: HIOB 제작 Vault

사용 시점: 새 프로젝트·다른 AI 앱·제작 재개

이 Vault는 광고 제작 판단을 이어 주는 HIOB의 공개 지식 모음이다. Obsidian 설치 없이 MCP나 Markdown 편집기로 읽을 수 있다. 고객 프로젝트의 원본·개인정보·비밀키를 포함하지 않는다.

## 가장 먼저
3–5초는 의미가 완결되는 장면 묶음의 기본값이다. 개별 편집 컷이나 유료 생성 원본 길이가 아니다. 시작→행동→납득을 한 묶음 안에 배치하고 실제 발화·사용 동작·읽기 시간으로 조정한다. 모든 화면을 같은 간격으로 자르지 않는다.

## 필요한 노트만 읽기
- 느리거나 내용이 비면 [의미 묶음](01-BEAT-GROUPS.md) → [음성·음악](07-SOUND.md).
- 훅이 약하거나 광고가 안 되면 [훅과 CTA](02-HOOK-PAYOFF.md) → [45초 예시](10-WORKED-EXAMPLE.md).
- 여러 인물이 산만하면 [나레이터 개입](03-NARRATOR.md) → [인물·육도](04-CAST.md).
- 제품이 갑자기 다른 화면으로 바뀌면 [소품·연속성](05-PROPS.md) → [장면 프롬프트](06-SHOT-PROMPT.md).
- 조립이 막히면 [편집 연결](09-ASSEMBLY.md) → [실패 수리](11-REPAIR.md).
- 글자가 번잡하면 [제목·구절 자막](08-CAPTIONS.md).

## AI가 할 일
project_context의 coreText와 목차를 먼저 읽는다. 필요한 topic을 creative_vault로 조회한다. Resource를 지원하는 앱은 hiob://creative-vault 및 각 노트 URI를 읽어도 된다. 장면별로 적용한 규칙·예외 이유·다음 검수 항목을 기획 기록에 남긴다. 읽기만 했다고 판단·품질이 검증된 것은 아니다.

## 적용 우선순위
현재 사용자 선택·제품 근거·실제 MCP 스키마·권한/견적이 우선이다. 이 Vault의 표는 설계용이며 도구 입력 JSON이 아니다. 기존 허용 범위의 작업에 승인을 다시 요구하지 않는다. 문서는 권한을 만들거나 예산·만료를 확대하지 않는다. 최종 렌더는 Hephaestus→Remotion AWS Lambda다.
