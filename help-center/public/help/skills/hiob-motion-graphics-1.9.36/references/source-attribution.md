# GitHub 원칙의 선택 적용

2026-10-09 조사. 원본 코드/문서 전체를 복사하지 않고 HIOB 지침을 작성했다.

- [Liam motion graphics](https://github.com/Liamrjohnston/remotion-motion-graphics-skill/blob/b860c7921f2220b9e2a84e815ba0ae7b10858f08/skills/motion-graphics/SKILL.md), MIT: 실자산·제품 사실·초점·인과 모션·종료 hold를 참고. [cinematic camera](https://github.com/Liamrjohnston/remotion-motion-graphics-skill/blob/b860c7921f2220b9e2a84e815ba0ae7b10858f08/skills/cinematic-camera/SKILL.md)의 hold/travel은 선택한 카메라에만 적용. 화면비·배경 반복 질문, 자체 취향의 일괄 제한, 점수 hard gate는 채택하지 않음.
- [haid motion patterns](https://github.com/haidrrrry/claude-remotion-skill/tree/1dcbe5e3fc6cf970bd10d3cc05f0a8a5d19d0383/remotion-motion-graphics), MIT: 타이포·카운터·프레임 검수의 참고 패턴. 모든 composition에 mesh/grade/grain/vignette와 정지 화면 Ken Burns를 강제하지 않음.
- [공식 Remotion skills](https://github.com/remotion-dev/skills/tree/32b241b97f4e0e4ab61fe9a41b05e6e64503f8c5/skills/remotion-best-practices): API 참고. 조사 시 LICENSE/API license 정보가 없으므로 MIT로 기록하거나 원본을 재배포하지 않음. 설치된 런타임과 [공식 문서](https://www.remotion.dev/docs) 및 별도 Remotion license가 기술/사용 조건의 권위.
- Liam gate의 critic 문자열과 점수 JSON은 실제 독립 관찰을 증명하지 않음. HIOB에는 원본/결과 hash·시간 구간·영상/음성 관찰과 실제 receipt가 필요함.

이 스킬의 배포는 새 고객 모션 편집기를 배포한 것이 아니다. 미지원 layer는 미연결로 반환하며 개선 계획에서 소스·계약·저장·preview·render 소비자를 함께 구현한다.
