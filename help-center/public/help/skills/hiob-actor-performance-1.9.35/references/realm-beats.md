# 육도와 사건의 관계

realm은 표정 preset이 아니다. 아래 출발점은 고객 상황과 승인 선택에 따라 구체화하며 모든 영상에 여섯 realm을 강제하지 않는다. 과거 영혼의 3배역·최소 4realm 조건을 최신 단일 나레이터/선택 경로에 되살리지 않는다.

| 육도 | 인간 상황의 출발점 | 관찰 가능한 연기 후보 |
|---|---|---|
| 지옥 | 압박·갇힘·긴장 | 급한 상황에서 시선/턱/손의 긴장, 사건 뒤 이완되는지 |
| 축생 | 두려움·경계·방어 | 접근을 망설이는 몸, 확인 뒤 방어가 풀리는지 |
| 아수라 | 비교·경쟁·좌절 | 다른 결과를 보는 시선, 힘/속도 변화와 좌절의 잔류 |
| 인간 | 분투·의심·시도 | 확인→시험→판단의 손/자세, 근거를 만난 뒤 다음 행동 |
| 아귀 | 갈망·기대·부족 | 필요한 것에 향하는 시선/손, 기대와 억제의 차이 |
| 천상 | 실제 해결 뒤 얻어낸 안도 | 성공 사건 뒤 호흡·어깨·그립이 자연스럽게 풀림 |

각 컷의 표에는 승인 expression/action, objective, trigger, 시작 상태, 행동, 반응, 잔류, 소품 상태, 카메라 이유, 실제 음성 구간을 적는다. objective/trigger라는 새 API 필드를 만들지 않는다. 계획에 없는 제품 효능·사용 사건을 만들어 안도를 얻었다고 연기시키지 않는다.

## 실패 사례와 보존

- 모든 컷이 human + 집중 + slight nod: 저장 label은 있어도 서로 다른 사건/반응이 드러나지 않는다. 원본을 보고 어느 구간의 변화가 누락됐는지 기록한 뒤 후보를 만든다.
- 압박에서 안도로 간다고 적었지만 성공 사건이 없다: 설명/제품 증거가 빠진 연출 후보다.
- 손 전용 컷을 absent로 선언: 실제 손·브랜드·그립·좌우·접촉/그림자 검수를 생략한 것이다.
- 더 풍부한 연기 때문에 기존 승인 대사/타이밍을 변경: 자동 수용하지 않는다. 승인 내 동작 범위로 축소하거나 별도 수정 후보로 남긴다.
- 천상이라 항상 미소/푸시인: 일괄 preset이 아니라 실제 해결 사건과 몸의 잔류로 설계한다.
