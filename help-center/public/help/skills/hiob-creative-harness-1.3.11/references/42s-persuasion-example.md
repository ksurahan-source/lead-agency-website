# 42초 한국어 릴스: 구매 이유가 이어지는 전체 예시

버전: 2026-10-03. 가상의 책상 정리함을 사용한 기획 예시다. 실제 고객 제품·사용 후기·유명인 발언·성능을 주장하지 않는다. “칸이 구분된 제품이며 실제 규격 자료가 있다”는 가정은 본인 제품의 원자료로 대체한다. 시간은 녹음 전 초안이며 실제 발화와 동영상은 미제작이다.

## 문제 공감형 전체 대본·동작표

| 시간 | 역할 | 한국어 대사 초안 | 실제 동영상/자료와 소리 |
|---|---|---|---|
| 0–3 | 훅 | “방금 쓴 펜, 또 찾고 있죠?” | 손이 책상 위 물건을 들추다 멈춤. 손·종이 소리. 사진 줌으로 대체하지 않음 |
| 3–7 | 공감 | “급할 때마다 종이 밑을 뒤지고, 서랍까지 열게 돼요.” | 같은 사람이 종이를 들고 서랍을 엶. 행동과 발화가 이어짐 |
| 7–12 | 공감·원인 단서 | “한곳에 모아도 물건끼리 가리면, 다시 찾게 되니까요.” | 펜 위로 물건이 놓이는 상황. 제품의 빈 칸을 다음 행동의 단서로 짧게 보여 줌 |
| 12–17 | 제품 차이 | “이 정리함은 칸이 나뉘어 있어요.” | 실제 확인된 제품 구조 근접. 손이 칸을 짚음. 다른 제품 이미지로 치환하지 않음 |
| 17–22 | 작동 방식 | “펜은 여기, 클립은 이쪽. 물건마다 둘 자리를 정해요.” | 손이 펜과 클립을 각 칸에 넣음. 접촉·수량·제품 형태 검수 |
| 22–27 | 고객 이점 | “다시 쓸 때는, 정해 둔 칸에서 꺼내는 방식이에요.” | 같은 손이 같은 펜을 꺼냄. 연출된 사용 방식이며 시간 절감 실험으로 표시하지 않음 |
| 27–32 | 제품 증거 | “실제 칸 구성과 크기는 여기서 확인할 수 있어요.” | 원자료의 관련 부분과 출처를 읽을 수 있게 보여 줌. 없는 규격 숫자를 생성하지 않음 |
| 32–37 | 구매 반론 | “내가 쓰는 물건이 들어가는지, 칸 크기는 꼭 비교해 보세요.” | 실제 규격과 사용할 물건을 함께 확인. 규격 자료가 없으면 이 구간은 자료 미확보 |
| 37–42 | 회수·CTA | “다시 찾기 전에, 내 책상에 맞는 구성을 확인해 보세요.” | 첫 화면과 같은 구도에서 펜을 꺼내 사용. 실제 구성 안내 페이지로 연결하는 CTA 하나 |

이 예시는 고객 후기가 없으므로 27–37초를 **제품 근거+선택 조건**으로 썼다. 사회적 증거가 있는 것으로 표시하지 않는다. 사회적 증거가 필요하면 실제 고객 원문·사용 조건을 확보한 뒤 해당 구간을 교체한다. 고객 인물이나 별점·리뷰 수를 AI로 만들어 채우지 않는다.

## 유명인의 말로 시작하는 변형

인용 원자료가 있을 때만 0–12초를 아래처럼 바꾼다. 아래 대괄호는 미확정 자리이며 그대로 음성 합성하지 않는다.

- 0–3초: `[인물/직함]의 [확인된 짧은 원문 또는 정확한 요약]`.
- 3–7초: “이 말을 책상에 적용하면, 물건을 어디에 둘지 정하는 문제예요.” 원래 발언이 실제로 이 해석을 뒷받침할 때만 사용.
- 7–12초: “한곳에 모으는 것과, 물건마다 자리가 있는 건 다르니까요.” 제품 구조와 관련된 문제로 연결.
- 12–27초: 위 표의 확인된 제품 차이·작동 방식·이점.
- 27–37초: 제품 자체의 자료 또는 실제 후기. 유명인의 일반 발언을 제품 추천으로 반복하지 않음.
- 37–42초: 처음 제시한 선택 기준을 회수하는 행동 하나.

맞는 발언이 없으면 문제 공감형을 사용한다. 유명인 이름을 먼저 정하고 그 사람의 말을 지어내지 않는다. 실제 제품 추천 자료가 있다면 일반 발언형과 달리 해당 제품·발언 시점·원문·사용 조건을 명시한다.

## 세 문장 비교

| 약한 문장 | 필요한 질문 | 근거가 있을 때의 수정 방향 |
|---|---|---|
| “프리미엄이라 편리해요.” | 어떤 구조가 어떤 행동을 돕는가? | “칸이 나뉘어 있어 물건별로 자리를 정할 수 있어요.” |
| “다들 만족하더라고요.” | 실제 누구의 어떤 경험인가? | 확인된 고객 원문을 짧게 쓰고 사용 조건·출처를 표시. 없으면 제거 |
| “전문가도 추천하는 제품.” | 이 제품의 실제 추천인가, 일반 발언인가? | 일반 발언이면 선택 기준으로 소개하고 제품 근거는 별도로 설명 |

## 길이·영상 검수

1. 본편 42초와 0–3/3–12/12–27/27–37/37–42의 역할을 브리프에 기록한다. 생성 원본 수는 이 다섯 구간 수와 같을 필요가 없다.
2. 3–5초 의미 묶음은 위 전체 설득 구간 안의 편집 단위다. 각 묶음이 별도 광고·별도 유료 생성 요청은 아니다.
3. 한국어 대사를 실제로 읽고 선택 음원의 발화·쉼·끝음절을 확인한다. 문장이 짧으면 필요한 사용 과정을 보여 주고, 길면 의미를 보존해 대사를 고친다. 무조건 늘리기·배속·같은 영상 반복을 하지 않는다.
4. 참조 이미지는 별도 칸에, 실제 동영상 원본은 ID/해시/사용 in-out에 기록한다. 사용 동작의 시작과 끝을 실제 재생으로 확인한다.
5. `plan.durationSec`와 beats·direction cuts·오디오·최종 MP4 길이를 비교한다. 42초에 못 미치면 빠진 역할과 원인을 기록하고 짧은 시안을 완성본으로 전달하지 않는다.
6. 이 문서의 존재나 숫자 합계 통과를 실제 발화·동작·광고 성과 검증으로 보고하지 않는다.
