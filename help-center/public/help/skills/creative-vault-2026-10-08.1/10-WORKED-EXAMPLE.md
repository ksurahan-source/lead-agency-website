# 45초 설계 예시: 묶음에서 컷으로

사용 시점: 처음부터 전체 기획표를 따라 만들 때

## 예시 조건
가상의 책상 정리함 광고다. 실제 판매 제품이나 사용 경험을 주장하지 않는다. 제품의 칸 구조·규격이 자료로 확인됐다고 가정한 설계 템플릿이다. 본인 제품의 사실로 대체한다. 아래 시간은 실제 녹음 전 가설이며 음성 생성·렌더·성과 검증을 한 결과가 아니다.

## 전체 흐름
- G01 0–4초 / 찾는 손→가려진 펜→표정 / 나레이터 “방금 놓은 펜, 또 찾고 있죠?” / 상황.
- G02 4–8초 / 주인공이 물건을 옮김→빈 자리 / “없는 게 아니라, 자리가 없는 걸지도요.” / 계속 볼 이유.
- G03 8–12초 / 또 찾는 손→시선 / 주인공 “여기 있었네.” / 반복 대처의 손실.
- G04 12–16초 / 조력자가 정리함을 가리킴→손으로 집음 / 나레이터 “자리를 정해볼까요?” / 제품 등장 이유.
- G05 16–20초 / 같은 공간에서 펜을 칸에 넣음→제품 근접 / “자료에서 확인한 칸 구성입니다.” / 실제 제품 근거로 교체할 문장.
- G06 20–24초 / 클립을 다른 칸에 놓음→손을 뗌 / “쓰는 물건별로 나눠 두고요.” / 확인된 사용 맥락.
- G07 24–28초 / 앞 장면과 같은 손이 펜을 꺼냄→반응 / 주인공 “아, 여기.” / 연출된 행동, 성능 입증 아님.
- G08 28–32초 / 책상과 제품 전체→규격 정보 / “책상에 맞는 크기는 확인하세요.” / 선택 조건.
- G09 32–36초 / 정리 전후 같은 구도 / 나레이터가 변화의 의미를 짧게 받음 / 실제 소품 배치 변화만 표현.
- G10 36–40초 / 첫 장면과 같은 손이 정해진 위치로 감 / “이번에는 어디 뒀는지 알겠죠?” / 시작 질문 회수.
- G11 40–45초 / 제품과 주인공의 짧은 반응→CTA / “내 책상에 맞는 구성을 확인하세요.” / 실제 연결 페이지의 행동으로 교체.

## G04를 더 자세히
12.0–13.2초 조력자의 시선/손 → 13.2–14.3초 제품을 집는 주인공 손 → 14.3–16.0초 같은 제품을 둘 자리. “자리를 정해볼까요?”가 이 컷들을 잇는다. 각 컷은 별도 생성이 아니라 검수한 원본의 해당 구간일 수 있다. 원본에 동작이 없으면 다른 원본을 확보한다.

## 자료 목록
CHAR_01 주인공, CHAR_02 조력자(필요한 구간만), PROP_01 제품, 펜·클립, 같은 책상 배경. 장면 첫 이미지는 카드 모음을 그대로 쓰지 않고 해당 인물·제품·행동을 한 프레임으로 구성한다.

## AI 프롬프트
이 예시의 제품명·대사를 복사하지 말고 내 브리프의 [불편→선택 이유→조건→다음 행동]에 맞춰 그룹표를 새로 만들어. 각 그룹의 실제 발화 길이를 확보한 뒤 컷 경계를 보정해. 총 길이와 컷 수는 결과로 계산하고 45초·24컷을 맞추려고 불필요한 장면을 늘리지 마.

## 한국어 구매 설득형 42초 예시

위45초 예시와 별도로 creative_harness(platform:"reels",mode)가 한국 릴스 설득 가이드와42초 전체 대본·동작표를 반환한다. 유명인 인용형/문제 공감형을 선택하고 제품의 차이·작동 방식·고객 이점을 근거와 연결한다. 고객이42초를 지정하면 총 길이를 임의 축약하지 않는다. 참조 이미지3장과 생성 원본은42초 본편의 준비물이며 완성본이 아니다.
