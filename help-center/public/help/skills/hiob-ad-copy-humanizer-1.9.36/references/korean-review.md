# 한국어 광고 검수 10기준

1. 옆에 있는 고객에게 직접 설명하듯 말한다. 번역체·과잉 높임·명사형 겹침을 고친다.
2. 앞 문장이 만든 질문을 다음 문장이 해결한다. 전환어만 붙여 논리 공백을 숨기지 않는다.
3. 고객이 처한 실제 상황과 제품 동작을 구체적으로 연결한다. 창작 장면과 실제 고객 증거를 구분한다.
4. 한 고통과 실제 구매 반론에 집중한다. 기능 나열을 후킹으로 착각하지 않는다.
5. 초반 전복 또는 후반 재해석은 제품 차이가 있어야 성립한다. 근거 없는 자극을 만들지 않는다.
6. 고객 질문을 자연스럽게 풀되 거짓 반론·후기·1인칭 체험을 발명하지 않는다.
7. 원문의 가격·비율·기간·조건·예외를 유지한다. 간결하게 고치며 구매 판단 정보를 지우지 않는다.
8. CTA는 앞의 이유와 이어지는 실제 행동이다. 결과를 보장하거나 지원되지 않는 서비스를 제안하지 않는다.
9. 선택한 화자 구성의 수정 전문을 반환한다. 승인 원문·지정 목소리·타이밍은 자동 변경하지 않는다.
10. 낭독/실제 합성 음성으로 발음·호흡·의미를 검토한다. 미관찰이면 pass를 만들지 않는다. 고객의 채택·거부 표현을 먼저 적용한다.

## 사례 판단

- “예약금 30%”를 “가벼운 예약금”으로 바꾸면 숫자 정보 손실이다. 자연스러운 문장에도 30%와 실제 조건을 남긴다.
- “제가 써보니”를 더하면 실제 체험 출처가 필요하다. 없으면 제품이 하는 일과 고객 상황으로 다시 쓴다.
- 고객이 거부한 문구를 후킹 점수 때문에 되살리면 실패다. 거부 내역을 source ledger에 유지한다.
- 매끄러운 문체지만 근거/제품이 없어도 성립하는 반전이면 재작성 후보로 남긴다.

고정 평가 양식: 원문→기준 번호→이유→남은 질문→대체 문장→전체 후보→claim ledger. 기존 승인과 후보를 비교한 뒤 선택을 저장한다. 점수나 이 체크리스트 통과는 광고 전환 성과를 입증하지 않는다.
