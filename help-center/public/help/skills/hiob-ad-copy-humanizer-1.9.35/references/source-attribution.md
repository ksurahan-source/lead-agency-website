# 조사와 적용 범위

2026-10-09 조사. HIOB 지침은 독립적으로 작성했으며 원본 스킬/실행기를 복사하지 않았다.

- [blader/humanizer](https://github.com/blader/humanizer/blob/225a6f39ac85f76ee48dbad772ea4abe4ed6c9d8/SKILL.md), v3.1.0, MIT. 과장·공허한 도입·장식적 구조를 고치고 주장을 유지하는 원칙을 참고했다. 영어 사례는 한국어 금칙어 목록이나 한국어 광고 성과의 검증이 아니다. 파일 자동 덮어쓰기와 꾸며낸 1인칭 체험은 채택하지 않는다.
- HIOB 2026-10-04 고객 본능/전복과 한국어 10기준이 우선한다. Janus/Karma/Parzifal/Artemis 실제 출처/receipt, 한 나레이터 승인 전문, 고객 채택/거부 내역을 보존한다.
- [promptfoo assertion 예제](https://github.com/promptfoo/promptfoo/blob/3df043590ca93e3f3d426307cfa0f1c2019817cc/examples/eval-javascript-assert-external/promptfooconfig.yaml): 숫자/조건 유실, 거부 문구 부활, 원문 무단 변경을 regression fixture로 관리하는 방법을 참고했다. 별도 provider 평가 호출이나 서비스를 설치하지 않았다.

미구현: 이 스킬은 자동 카피 생성 모델·성과 예측·대본 승인 엔진이 아니다. 호스트가 읽고 현재 제작 도구에 적용하는 지침이다. SOURCE/WIRED/DEPLOYED와 고객이 실제 음성을 듣고 수정안을 채택한 증거를 구분한다.
